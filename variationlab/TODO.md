# Variation Lab Live — delivery outcomes

## Anonymous submission portal

- [ ] Students can submit individual data anonymously, without names, login, codes, or identifying metadata.
- [ ] Investigation 1 accepts body mass in kg with sensible standard-human bounds.
- [ ] Investigation 2 accepts height in cm with sensible standard-human bounds.
- [ ] Investigation 3 accepts hand span width in cm.
- [ ] Investigation 4 offers Can / Cannot tongue rolling choices.
- [ ] Investigation 5 offers Brown / Blue / Green / Hazel eye colour choices.
- [ ] Investigation 6 offers simulated A / B / AB / O blood-group choices.
- [ ] Investigation 7 provides a dynamic multi-entry grid for multiple leaf-length measurements in cm.
- [ ] Investigation 8 accepts decimal seed mass in grams.
- [ ] Investigation 8 provides an "add row" control for multiple decimal seed-mass measurements and includes every entered row in the live histogram.
- [ ] A single submit action persists any completed investigation values and provides clear validation feedback.

## Live shared dashboard

- [ ] The shared display updates without a forced reload when new submissions arrive.
- [ ] Investigations 1, 2, 3, 7, and 8 show interactive histograms with touching bars and automatically adapting class intervals.
- [ ] Investigations 4, 5, and 6 show interactive separated bar charts with category tallies.
- [ ] The live total sample size N is visible and reflects active database rows.
- [ ] The interface communicates the slide guidance that measurements are continuous, categories are discontinuous, and grouped totals protect privacy.

## Teacher utilities

- [ ] Export to CSV is hidden behind teacher controls and requires the teacher key.
- [ ] Clear Database is hidden behind teacher controls, requires the teacher key, and confirms before destructive deletion.
- [ ] The server persists data in the managed database infrastructure; no external database configuration is required.

## Source visuals and delivery

- [ ] The newly attached PDF artwork is used exclusively: the cover collage is the large header without Name/Date lines, the title uses a more stylish website font, and the left entry panel contains no pictures.
- [ ] The app has a route manifest, builds cleanly, and is ready for Preview/checkpoint delivery.

## Accessibility and lesson visuals

- [ ] Students must explicitly give consent before a submission can be sent; participation remains optional and consent is not stored with identifying data.
- [ ] Essential classroom labels, inputs, actions, and chart titles use large-print typography at 26px or larger.
- [ ] Each investigation chart has a large matching picture crop from the PDF beside it, the lesson-visual section is removed, and student-facing grouping labels do not classify investigations as continuous or discontinuous.
- [ ] Dashboard cards appear in chronological Investigation 1–8 order, and the two header pictures touch with no white gap.
